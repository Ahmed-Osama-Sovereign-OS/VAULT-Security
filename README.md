# VAULT - Secure Security System
Developed by: **Ahmed Osama**

VAULT is a professional-grade security toolkit for Windows, designed for local data encryption, permanent file destruction, and network monitoring.

## Features
- **AES-256 Vault:** Secure your sensitive files with industrial-strength encryption.
- **Secure Shredder:** Permanently delete files beyond recovery using multi-pass overwriting.
- **Network Sentinel:** Real-time monitoring of active network connections to detect unauthorized processes.
